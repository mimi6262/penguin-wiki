## 고블린 마을

| 드랍 아이템 | 설명 |
|-----------|------|
| 부패된 이빨 | 고블린 워리어에게 드랍되며 5티어 장비(무기,모자,룬)의 재료로 사용됩니다. |
| 부패된 화살 | 고블린 아처에게 드랍되며 5티어 장비(무기,갑옷,룬)의 재료로 사용됩니다. |
| 부패된 단검 | 고블린 어쎄신에게 드랍되며 5티어 장비(무기,바지,룬)의 재료로 사용됩니다. |
| 부패된 완드 | 고블린 샤먼에게 드랍되며 5티어 장비(무기,신발,룬)의 재료로 사용됩니다. |
| 4티어 정수 | 고블린 마을의 모든 몹에게 드랍되며 모든 아이템의 재료로 사용됩니다. |
| 4티어 제련석 조각 | 고블린 마을의 모든 몹에게 드랍되며 4개로 제련석으로 조합이 가능합니다. |
| 4티어 제련석 | 낮은 확률로 몹에게서 드랍되거나 제련석 조각으로 만들수 있으며 모든 아이템의 재료로 사용됩니다. |
| 4티어 보스 제련석 | 감염된 고블린에게 드랍되며 RPG 반지의 재료로 사용됩니다. |
