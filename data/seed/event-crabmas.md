## 2025년 12월 15일 변경사항

**낚시 플러그인 v30 기준**

### ➕ 추가 사항

* **크랩마스 보스 처치 시**, 낮은 확률로 **엔트로피 크리스탈 x5**가 추가 드롭되도록 변경되었습니다.

### 🔄 변경 사항

* **크랩마스 보스 이동 속도**가 소폭 증가했습니다.
* **크랩마스 오브 활성화 상태에서 보스가 낚일 확률**이 상향 조정되었습니다.
  * 기존 : **1 / 70**
  * 변경 : **1 / 30 (약 3.33%)**
  * → 보스를 더 빠르고 안정적으로 만날 수 있습니다.

### 🛠 버그 수정

* 아주 드물게 **모든 바이옴이 제외되는 문제**를 수정했습니다.
* 안내 **메시지가 1회만 출력되어야 함에도 반복 출력되던 문제**를 수정했습니다.
* 그 외 이미 발생했거나 발생 가능했던 **여러 잠재적인 문제들을 추가 검증과 함께 수정**했습니다.

## ⏰ 이벤트 기간

📅 **2025년 12월 12일 ~ 12월 31일 23:59**

총 20일간 진행되는 한정 이벤트입니다.

*이벤트 기간 종료 후에는 크랩마스 이벤트, 보스, 전용 보상을 모두 획득할 수 없습니다.*

---

## 📌 이벤트 참여 방법

### 1. 이벤트 바이옴 확인

```
/fish events CRABMAS
```

명령어를 입력해 현재 크랩마스 바이옴이 발견되었는지 확인합니다.
('알 수 없음…'이면 아직 미발견 상태)

### 2. 바이옴 탐색

```
/fish events CRABMAS biomes
```

아직 발견되지 않았다면, 아래에 나열된 크랩마스 등장 가능 바이옴 중 한 곳에서 낚시를 진행합니다.

누군가 먼저 발견하면 서버 전체에 방송 메시지가 출력됩니다.

### 3. 낚시를 통한 바이옴 판별

같은 바이옴에서 일정 수의 물고기를 낚으면 해당 바이옴이 크랩마스 바이옴인지 자동으로 판별됩니다.

* 서버 인원 40명 이상 → 40마리 낚시
* 서버 인원 39명 이하 → 현재 서버 인원 수만큼 낚시
* 해당 바이옴에서 2시간 동안 발견 실패 시, 최대 필요 수량이 40 → 30으로 감소

잘못된 바이옴일 경우 자동 안내 메시지가 출력됩니다.

### 4. 방송 이후 효과

방송 메시지를 수신한 이후부터 낚시 중 **일반 크랩마스가 2% 확률로 등장**합니다.

※ 해당 확률은 크랩 미끼 / 크랩 루어 사용량과 무관합니다.

### 5. 크랩마스 처치

일반 크랩마스를 처치하면 **크랩마스 오브**를 드롭합니다.

크랩마스 바이옴을 직접 발견한 경우, 오브를 1개가 아닌 2개 획득합니다.

### 6. 보스 소환

* 크랩마스 오브 5개 이상 보유
* 공중을 향해 우클릭 사용

오브를 활성화하면 크랩마스 보스가 확률적으로 등장합니다.

### 7. 보스 처치

보스를 처치하면 무작위 이벤트 전용 보상 1종을 획득합니다.

이벤트 전용 어그멘트를 얻을 때까지 반복 가능합니다.

* 보스가 10초 이상 생존 시 전기뱀장어 20마리 소환
* 10초 내 처치 실패 시

  * 플레이어에게만 피해
  * 블록 및 동물 피해 없음
* 전기뱀장어는 폭발 공격을 제외한 모든 공격으로 처치 가능

## ❓ FAQ

**Q. 크랩마스는 얼마나 유지되나요?**

* 일반 바이옴 : 60분
* 추운 / 눈 덮인 바이옴 : 90분

**Q. 현재 상태는 어떻게 확인하나요?**

```
/fish events CRABMAS
```

명령어로 진행 상태 및 남은 시간을 확인할 수 있습니다.

**Q. 로그아웃하면 크랩마스 보스 확정 소환 확률이 사라지나요?**

아니요. 보스 확정 소환 보장은 로그아웃으로 초기화되지 않습니다.

다만, 아래 경우에는 보장이 초기화됩니다.

* 보스가 실제로 소환 되었을 경우
* 서버가 재시작 되었을 경우
