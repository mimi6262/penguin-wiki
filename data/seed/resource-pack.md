## 서버 자동 적용

1. 마인크래프트 자바 에디션 **1.21.4**을 실행합니다.
2. 메인 메뉴에서 **[멀티 플레이]**를 클릭합니다.
3. 우측 하단의 **[서버 추가]**를 클릭합니다.
4. 서버 주소 입력 및 **서버 리소스 팩: 사용**으로 선택 후 **[완료]** 클릭합니다.

## 수동 적용

1. 디스코드 서버의 **리소스팩\_수동다운** 채널에 업로드된 최신 리소스팩 `.zip` 파일을 다운로드합니다.

2. 다운로드한 `.zip` 파일을 다음 경로에 복사합니다.

```
Windows
%appdata%\.minecraft\resourcepacks

macOS
~/Library/Application Support/minecraft/resourcepacks
```

3. 마인크래프트를 실행하고, 메인 메뉴에서 **[설정] → [리소스팩]** 메뉴로 이동합니다.

4. 좌측에 있는 다운로드한 리소스팩을 찾아 **오른쪽으로 이동**시켜 활성화합니다.

5. **[완료]** 버튼을 클릭하면 게임 내에서 리소스팩이 적용됩니다.

> [!안내] 리소스팩을 직접 적용한 경우, 서버 리소스팩 옵션이 "사용 안 함"으로 되어 있어도 상관없습니다.

## 기타

**서버 리소스팩 로드 실패** 시, 대다수 원인은 큰 용량의 리소스팩(특히 고해상도 텍스처)으로 인해 RAM 또는 VRAM 부족이 발생하는 경우입니다.

* **RAM(메모리)**은 PC 사양에 따라 마인크래프트 런처 설정에서 할당량을 늘려 해결할 수 있습니다. *(예: 런처 > 설치 설정 > "추가 인수"에서 `-Xmx4G` 등으로 조정)*

* **VRAM(그래픽 메모리)**은 그래픽카드의 물리적 용량에 의존하므로, **내장그래픽** 또는 **GTX 1060 3GB 이하 모델**에서는 해결이 어렵습니다.

이 경우 서버 리소스팩이 자동으로 다운로드되더라도 로드 중 멈추거나 일부 텍스처, GUI, 몬스터 모델 등이 정상적으로 표시되지 않을 수 있습니다.
