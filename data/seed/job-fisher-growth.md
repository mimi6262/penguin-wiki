## 🎣 레벨 체계

어부 직업에는 두 가지 레벨 시스템이 있어요.

| | 생활직업 레벨 | 파이로피시 레벨 |
|---|---|---|
| 확인 방법 | `/skill` 명령어 | 낚싯대를 들고 `Shift + 클릭` |
| 오르는 방법 | 낚시 활동 | 낚시 활동 |
| 주요 용도 | 어부 승급 조건 충족 | 토템, 낚시 스킬, 어그멘트 제작 |

## 엔트로피

* 낚싯대 강화 및 어그멘트 제작에 쓰이는 재화예요.
* **확인 방법** : 낚싯대를 들고 `Shift + 좌클릭` → 어그멘트 메뉴

## 어그멘트

낚싯대에 장착해서 다양한 효과를 얻을 수 있는 강화 시스템이에요.

* **제작** : 요구 레벨과 재료를 **가마솥**에 드랍 → 낚싯대를 들고 `좌클릭`
* **적용** : 낚싯대 들고 `Shift + 클릭` → 낚싯대 + 어그멘트를 슬롯에 넣고 `O키` 클릭
* **정보 확인** : `/fish augments`

> [!주의] 낚싯대를 **왼손**에 쥐고 낚시하면 어그멘트가 적용되지 않아요. 반드시 **오른손**에 들고 낚시해주세요!

| 어그멘트 | 최대 레벨(LV) | 설명 |

## 낚시 스킬

* 어부 레벨업 시 **스킬 포인트**를 획득해요.
* 낚싯대 메뉴 → **낚시 스킬**에서 포인트를 투자해 스킬을 습득할 수 있어요.

| 스킬 명 | 설명 |
|---|---|
| 더 나은 손질 | 물고기 손질 시 엔트로피를 더 많이 획득해요. 정밀한 절단 어그멘트와는 중첩되지 않고 **독립적으로 계산**돼요. |
| 행운의 낚시 | 물고기 낚을 때 엔트로피를 더 많이 획득해요. 다른 소스에서 얻은 보너스 엔트로피와 **독립적으로 계산**돼요. |
| 마스터 어그멘터 | 낚시 어그멘트 제작 비용이 줄어들어요. |
| 토템 리더 | 물고기를 잡을 때 토템 쿨다운이 감소해요. 보너스 물고기를 주는 어그멘트(예: 핫스팟)와는 **중첩되지 않아요**. |
| 신성한 심판 | 신성한 일격을 소환할 확률이 생겨요. 일격은 **쓰나미**를 발동시키고, 쓰나미에서 낚은 물고기는 모두 **2배**가 돼요. 같은 플레이어의 쓰나미는 중복 발동되지 않지만, 다른 플레이어는 내 쓰나미에서 혜택을 받을 수 있어요. 핫스팟 등 유사 효과는 쓰나미에 적용되지 않아요. |
| 트레블 샷 | 자신의 낚시 토템 범위 내 플레이어에게 효과의 일부를 공유해요. 토템 효과와 중첩되지 않으며, 내 토템과 다른 사람의 토템이 겹칠 경우 **내 것이 우선**돼요. 소유자는 원래 버프를 잃지 않아요. |
| 콤보 캐쳐 | 콤보를 쌓아 희귀 물고기 낚을 확률을 높여요. 최대 콤보는 레벨에 비례해 증가하며, **20회** 낚시 = 마스터 피셔맨 **10레벨**에 해당해요. **30초** 동안 물고기를 못 잡으면 콤보가 초기화돼요. |
| 어그멘트 환불 | 어그멘트 제작 시 재료 일부를 환불받을 확률이 생겨요. 확률은 각 아이템마다 **개별 계산**되며, 환불 시 사용 재료의 **50%** 가 돌아와요. |

## [어부 5차] 포세이돈 패시브

5차 승급을 완료한 어부만 사용할 수 있는 특별 패시브예요

* **설정 명령어** : `/패시브` (ON/OFF 전환 가능)
* 월드마다 개별 설정되며, 기본값은 **활성화** 상태예요.
* 명령어 사용이 **불가한 월드** : RPG, 스폰, 잠수존

### 1) 상시 수중 호흡 패시브

* 물속에서도 계속 숨을 쉴 수 있어요.
* 물 위에서 **웅크리기**를 하면 고속 이동이 가능해요.

### 2) 낚시 속도 증가 패시브

* 낚시 중 **3% 확률**로 '포세이돈의 가호' 효과 발동
  * 5분간 낚시 속도 **20% 증가**
  * 바닐라 비 효과와 중첩돼요.
  * 가호 효과는 중첩되지 않아요.
