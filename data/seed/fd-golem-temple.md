## 보스 드랍템

## 필드 드랍템

| 드랍 아이템 | 설명 |
|-----------|------|
| 골렘 파편 A | 미니 골렘 A에게 드랍되며 10티어 장비(무기,모자,룬,반지)의 재료로 사용됩니다. |
| 골렘 파편 B | 미니 골렘 B에게 드랍되며 10티어 장비(무기,갑옷,룬,반지)의 재료로 사용됩니다. |
| 코볼트 골렘파편 | 코볼트 골렘에게 드랍되며 10티어 장비(무기,바지,룬,반지)의 재료로 사용됩니다. |
| 트리플 골렘파편 | 트리플 골렘에게 드랍되며 10티어 장비(무기,신발,룬,반지)의 재료로 사용 |
| 8티어 정수 | 골렘 사원의 모든 몹에게 드랍되며 모든 아이템의 재료로 사용됩니다. |
| 9티어 제련석 조각 | 골렘 사원의 모든 몹에게 드랍되며 4개로 제련석으로 조합이 가능합니다. |
| 9티어 제련석 | 낮은 확률로 몹에게서 드랍되거나 제련석 조각으로 만들수 있으며 모든 아이템의 재료로 사용됩니다. |
| 9티어 보스 제련석 | 타이탄탄에게 드랍되며 RPG 반지의 재료로 사용됩니다. |
| 최하급 보석 | 상점에 5000원에 판매 가능한 아이템입니다. |
| 최상급 포션 | 체력과 마나를 80% 올려주는 아이템입니다. |
