## Forge (포지) 설치 방법

#### 설치 절차

1. **Forge 전용 보이스모드 파일 다운로드합니다.**
2. `mods` 폴더에 **다운로드한 보이스 모드 파일** 넣습니다.
3. 게임 실행 후 모드 정상 동작 여부 확인

---

## Fabric (패브릭) 설치 방법

#### 설치 절차

1. **Fabric API 파일 + 보이스모드 파일 다운로드합니다.**
2. `mods` 폴더에 다운로드한 파일을 넣습니다.
3. (필요 시) Iris / Sodium 모드

   보이스 모드 설치만으로는 충분하지 않은 경우 이 라이브러리를 추가해야 합니다.
4. 게임 실행 후 모드 정상 동작 여부 확인

---

### mods 폴더가 어디에 있나요?

| 운영체제 | 경로 |
|---------|------|
| **윈도우 (Windows)** | 1. `Win + R` 키 입력<br>2. 실행 창에 `%appdata%` 입력<br>3. `.minecraft` 폴더 안에 `mods` 폴더 |
| **맥 (MacOS)** | 1. Finder 실행 → 상단 메뉴에서 `이동` 클릭<br>2. `폴더로 이동...` 선택 후 다음 입력:<br>`~/Library/Application Support/minecraft/mods` |
| **리눅스 (Linux)** | 홈 디렉토리 아래 다음 경로에 있음:<br>`~/.minecraft/mods` |

> [!안내] `mods` 폴더가 없을 경우, 직접 새로 만들어도 무방합니다.

---

### 게임 접속 시 공통 세팅

* 보이스 키는 `설정 → 키 설정 → 보이스 채팅`에서 변경 가능
* 마이크 인식이 안될 경우, OS의 **소리 입력 장치** 확인 후 게임 재실행

---

### 보이스 모드 사용법

* `V` 키를 누르면 **보이스 채팅 메뉴**가 열립니다.
* 여기서 **마이크 ON/OFF(음소거)**, **다른 사람 목소리 볼륨 조절**, 보이스 사용 모드(항상 켜짐 / 눌러서 말하기) 를 설정할 수 있습니다.
* 기본 단축키는 모두 변경 가능 (`설정 → 키 설정 → 보이스 채팅`)
