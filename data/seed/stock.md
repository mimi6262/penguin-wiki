주식 시스템은 스폰 NPC를 통해 주식을 사고팔고, 직접 회사를 설립해 운영할 수 있는 서버 경제 컨텐츠입니다.

## 시작

* **스폰에 있는 주식 NPC**를 눌러 주식을 살 수 있습니다.
* 원한다면 **디스코드 신청으로 내 회사를 직접 설립**할 수도 있습니다.

## 진행

* **가격은 2시간마다 랜덤으로 변동**됩니다.
* 가끔 **이벤트 뉴스**가 떠서 가격이 크게 오르거나 내릴 수 있습니다.
* 회사를 만든 사람은 **절반의 주식을 자동 보유**하고, 나머지는 유저들이 살 수 있습니다.
* 유저는 **한 회사당 최대 30주까지** 가질 수 있고, 여러 회사에 동시에 투자도 가능합니다.

---

## 주식 거래 방법

* 주식 NPC에게 말을 걸면 **주식 GUI 창**이 열립니다.
  * 좌클릭 → **구매**
  * 우클릭 → **판매**
  * 쉬프트 좌클릭 **→ 30개 구매**
  * 쉬프트 우클릭 **→ 전체 판매**
* 주식 NPC를 통해 **평단가(평균 매입 가격)**가 표시되어 현재 시세와 비교할 수 있습니다.

### 거래 기본 규칙

| 구분 | 내용 |
| --- | --- |
| 거래 단위 | 1주 단위 |
| 판매 수수료 | 없음 |
| 보유 제한 | 회사당 최대 30주 |
| 상장 폐지 조건 | 주가 100원 이하 시 자동 폐지 |
| 시세 변동 주기 | 2시간마다 랜덤 변동 |
| 변동 폭 | -4.7% ~ +5% |

---

## 뉴스 시스템

* **매 2시간**마다 **랜덤으로 이벤트**가 발동할 수 있습니다.
* 한 회사에 여러 번 연속 발생하거나, 어떤 회사에도 이벤트가 없을 수 있습니다.
* 이벤트가 발생하면 **모든월드 채팅**에 메시지가 출력되며, 특정 회사의 주가에 직접적인 영향을 줍니다.
  * 이벤트 변동은 **호재·악재 모두** 채팅에 표기됩니다.

### 📈 호재 이벤트 (주가 상승)

| 이벤트 내용 | 상승 폭 |
| --- | --- |
| 광산에서 다이아 발견, 주가 급등 | **1% ~ 8%** |
| 밀 농사 풍년으로 회사 호황 | **3% ~ 6%** |
| 엔더 드래곤 날개 독점 공급, 주가 치솟음 | **1% ~ 2%** |
| 신제품 출시로 투자 기대감 상승 | **2% ~ 4%** |
| 바다 탐험에서 보물 발견, 주가 폭등 | **3% ~ 6%** |

### 📉 악재 이벤트 (주가 하락)

| 이벤트 내용 | 하락 폭 |
| --- | --- |
| 크리퍼 폭발로 큰 피해 발생 | **1% ~ 8%** |
| TNT 폭발로 주식 붕괴 위기 | **3% ~ 6%** |
| 엔더맨이 자원을 빼돌려 주식 하락 | **1% ~ 2%** |
| 좀비 습격으로 피해 확산, 주가 폭락 | **2% ~ 4%** |
| 번개로 창고가 불타 주식 가치 하락 | **3% ~ 6%** |

## 주식 상장 시스템

* 유저는 **디스코드 건의 채널**을 통해 티켓을 열고 회사를 설립할 수 있습니다.
* **인당 최대 1개 회사**만 창립 가능하며, 금액대별로 선착순 제한이 있습니다.
  * 예) 1,000만원 / 2,000만원 n명까지 신청 가능
* 관리자가 티켓을 확인 후 **수동으로 상장 처리**하며, 처리 즉시 시장에 반영됩니다.
* 주식은 1천만원 주식 상장 가능 수 4인, 2천만원 상장 가능 수량 4인, 3천만원 상장 가능 수량 4인 이런식으로 금액별 최대 4개의 회사만 상장가능하며 유저별 1개의 회사만 상장이 가능합니다.

### 신청 양식 예시

* 회사 이름 : 호두마루
* 설립자 닉네임 : Wal_Nuts (영어 닉네임으로 제출)
* 지불할 돈 : 10,000,000 (아래 '**지불할 돈' 표** 참조)
* 아이콘 선택 (이미지 참고)

| 지불할 돈 | 상장 총액 | 유저가 받는 주 | 설립자 보유 지분 | 최초 상장가 |
| --- | --- | --- | --- | --- |
| ~~10,000,000~~ | 16,000,000 | 1250주 | 8,000,000 | 6,400 |
| ~~20,000,000~~ | 32,000,000 | 1250주 | 16,000,000 | 12,800 |
| ~~30,000,000~~ | 48,000,000 | 1250주 | 24,000,000 | 19,200 |

## 상장 이후 구조

* 상장 후 **총 2,500주**가 발행됩니다.
* 이 중 **1,250주는 설립자**가 자동 보유합니다.
* 나머지 **1,250주는 시장에 풀려** 다른 유저들이 구매할 수 있습니다.
* 유저는 회사당 **최대 30주**만 가질 수 있습니다.
* 여러 회사에 동시에 투자 가능하며, 각 회사마다 30주씩 보유 가능합니다.

---

## 주의사항 / 유의점

* 주가 변동 시 소수점은 모두 버림(내림 처리)됩니다. (예: 95.95 → 95원)
* 상장폐지 시 주식은 모두 휴지조각(0원)이 되며, **환불/보상 없습니다.**
* 설립자는 보유한 1,250주를 자유롭게 시장에 판매할 수 있습니다.
* 설립 후 **취소/양도 불가**합니다.
* 회사 **이름/아이콘 변경 불가**합니다. (설립 시 확정)
* 설립자가 장기간 미접속해도 회사는 유지되며, **상장폐지 전까지 계속 존재**합니다.
* 변동은 서버 경제와 무관, **랜덤성과 이벤트**로만 변동됩니다.
* 서버 재시작/점검 시에도 **주가가 롤백되지 않습니다.**
  * 재시작과 관계없이 **주가는 랜덤 변동이 계속 적용**됩니다.
