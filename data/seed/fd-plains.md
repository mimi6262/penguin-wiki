## 평원

### 드랍 아이템

| 드랍 아이템 | 설명 |
|---|---|
| 달팽이 점액 | 달팽이에게 드랍되며 2티어 장비(무기,모자,룬)의 재료로 사용됩니다. |
| 도마뱀 꼬리 | 도마뱀에게 드랍되며 2티어 장비(무기,갑옷,룬)의 재료로 사용됩니다. |
| 불도마뱀의 꼬리 | 불도마뱀에게 드랍되며 2티어 장비(무기,바지,룬)의 재료로 사용됩니다. |
| 유령의 영혼 | 유령에게 드랍되며 2티어 장비(무기,신발,룬)의 재료로 사용됩니다. |
| 1티어 정수 | 평원의 모든 몹에게 드랍되며 모든 아이템의 재료로 사용됩니다. |
| 1티어 제련석 조각 | 평원의 모든 몹에게 드랍되며 4개로 제련석으로 조합이 가능합니다. |
| 1티어 제련석 | 제련석 조각으로 만들수 있으며 모든 아이템의 재료로 사용됩니다. |
