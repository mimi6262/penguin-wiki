## 로또사용 방법

* 매일 자정 서버 자금으로 상금으로 10만원씩 상금이 추가됩니다.
* 당첨자가 없으면 총 상금은 다음 주로 이월됩니다.
* **미성년자는 로또 이용이 금지됩니다. 적발 시 밴처리됩니다.**

## 참여 방법

* 스폰에 위치한 로또 NPC를 통해 구매 가능합니다.
* 5개의 숫자를 선택 후, **[구매하기]** 버튼을 누르면 로또가 구매됩니다.
* 숫자를 선택하지 않고 구매하기 누르면 자동 번호로 발급됩니다.

## 추첨 일정

* 매주 금요일 21시
* 결과 발표: 펭귄서버 디스코드 #펭귄로또 채널
* 지급 방식 : 당첨자 발표 후, **스폰으로 이동 시 자동 지급**됩니다.

## 구매 제한 & 가격

* 일일 최대 구매 가능 수: 5장
* 1장 가격: 5,000원 - 구매 수수료 500원이 포함되어 있습니다.
* 구매 상금에는 4,500원만 누적됩니다.

## 상금 구성

* 당첨자가 여러명일 경우, **n분의 1로 계산**되어 **지급**됩니다.

| 등수 | 상금 |
|------|------|
| 🥇 특별보상 | 5개 다 맞출 시 총금액의 80% + 캐시 10만원 지급 |
| 🥇 1등 | 4개 맞을 시 총 금액의 80% 지급 (인게임머니) |
| 🥈 2등 | 3개 맞을 시 총 금액의 20% 지급 (인게임머니) |
| 🥉 3등 | 2개 맞을 시 15,000원 인게임머니 서버에서 지급 |
