## 어부 상점 & NPC

스폰 위치의 어부 상점 NPC에서 직업 승급을 진행할 수 있습니다. 미끼 NPC에서 미끼를 구매하며, 4차 미끼는 두 가지 종류가 있으므로 구매 전 확인이 필요합니다.

## 🐟 낚싯대 메뉴

낚싯대를 들고 **`Shift + 우클릭`**하면 다음 메뉴가 열립니다:

| 메뉴 | 설명 |
|------|------|
| 물고기 판매 상점 | 잡은 물고기를 모두 판매 |
| 배송 | 물고기 배송으로 인게임머니·엔트로피 획득 |
| 물고기 도감 | 등급별 물고기 도감 확인 |
| 무게 측정 | 무게에 따라 판매가 변동(±20% ~ ±80%) |
| 물고기 손질 | 커스텀 물고기 손질으로 엔트로피 획득 |
| 낚시 스킬 | 스킬 포인트 관리 |
| 미끼 상점 | 미끼 구매 후 낚싯대에 드래그 장착 |
| 어그멘트 | 제작법 확인 및 적용 |
| 토템 | 토템 설치 구조 확인 |

### 미끼

> [!안내]
> 커스텀 물고기는 반드시 **미끼가 필요**합니다. 차수가 높아질수록 더 다양한 미끼를 구매할 수 있습니다.

미끼 상점 또는 스폰 어부 상점에서 구매 후, 낚싯대에 드래그해서 장착합니다. 이름에 '식재료'가 붙은 1차·3차 미끼는 기본 물고기와 요리재료 물고기만 낚습니다.

| 차수 | 미끼 횟수 |
|------|----------|
| 0차 | 20번 |
| 1차 | 32번 |
| 2차 | 32번 |
| 3차 | 32번 |
| 4차 | 32번 |
| 4차 플레티넘 | 32번 |
| 4차 신화 | 64번 |
| 5차 | 120번 |

### 손질

커스텀 물고기만 가능하며, 손질 시 물고기를 **엔트로피**로 교환할 수 있습니다.

### 무게 측정

낚싯대 메뉴에서 커스텀 물고기를 계량할 수 있으며, 무게에 따라 판매가가 ±20% ~ ±80% 범위로 변동됩니다.

측정 방법:
1. 낚싯대 메뉴 열기(`Shift + 우클릭`) → **무게 측정** 클릭
2. 빈 슬롯에 계량할 커스텀 물고기를 넣기
3. 저울 버튼 클릭 후 하단 가운데 확인 버튼 클릭
4. 물고기에 마우스를 올리면 무게가 랜덤 수치로 결정되어 판매가 자동 조정

> [!안내]
> 같은 물고기라도 무게에 따라 판매가가 달라지므로 높은 가격을 원한다면 무게 측정을 해보세요.

### 판매

낚싯대 메뉴의 **물고기 판매 상점**을 이용하며, 손질 여부와 상관없이 판매할 수 있습니다.

## 🎁 물고기 등급 & 확률

브론즈 → 실버 → 골드 → 다이아몬드 → 플래티넘 → 신화

| 등급 | 확률(%) |
|------|---------|
| 브론즈 | 73.7% |

| 골드 | 7.8% |

| 플레티넘 | 0.3% |
| 신화 | 0.1% |
