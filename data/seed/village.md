## 마을 생성

1. `/마을 구매 마을명`을 입력 시, 자신이 서있는 위치에 마을이 생성됩니다.

## 마을 땅 비용

* 마을 땅은 기본 4청크까지 무료로 늘릴 수 있으며, 이후 1청크 당 **20,000원**씩 비용이 늘어납니다.
  * 20,000 → 40,000 → 60,000 → 80,000 ... 최대 200,000까지 비용 증가되며, 이후 청크 늘릴 시 200,000원고정됩니다.
* 마을 판매 시 마지막으로 구매한 청크의 비용은 환불되지 않으며, 이후 판매 시 100% 환불됩니다.
* 마을 최대 점유 가능 청크 수 : 500청크
* /마을 메뉴 를 통해 마을 청크 및 인원관리를 하실 수 있습니다.

## 마을 종 옮기는 방법

1. 마을 종을 `Shift+좌클릭` 합니다.
2. 메뉴 하단에 종 아이콘을 클릭하면 종이 사라집니다.
3. 옮기고 싶은 장소에서 `/마을 메뉴` 명령어를 입력합니다.
4. 메뉴 하단 우측에 종 아이콘을 클릭하면 다시 종이 나타납니다.

## 마을 붙이기 기능

> [!주의] 이미지와 같이 Tenant 역할이 아닌 다른 역할로 골라서 진행 부탁드립니다.

### 마을 통합 시 주의사항

* 마을 기능의 모든 권한을 개방하여 사용하는 방식은 서버에서 권장드리지 않는 방법이므로, 이로 인한 피해 발생 시 서버 측에서 복구를 지원해드리기 어렵습니다.
* 또한 약탈 행위가 확인된 인원은 벤 처리되니 주의바랍니다.

## 마을 채팅

* **마을이 2개 이상** 소속되어 있는경우. 원하는 마을 채팅을 선택해 대화할 수 있습니다.
  * **`/마을 메뉴`** 명령어를 입력하여 마을 메뉴를 열 수 있습니다.
  * 채팅하고자 하는 마을을 **앞 순서로 이동**시키려면, 마을 아이콘을 **Shift + 좌클릭**하세요.
  * 아이콘이 맨 앞에 정렬되면, 해당 마을의 채팅창이 기본으로 적용됩니다.

## 마을 명령어

| 명령어 | 설명 |
|--------|------|
| `/마을 메뉴` 또는 `/land` | 마을 메뉴 GUI 창이 뜹니다. |
| `/마을 구매 [마을명]` 또는 `/land create [마을명]` | 서 있는 청크를 본인의 마을로 지정합니다. ※ 최대 4청크 무료, 5청크부터 2만원씩 증가 (최대 20만원) |
| `/마을 확장 [마을명]` 또는 `/land claim [마을명]` | 기존 마을 청크와 연결이 되어있는 상태에서 청크를 구매할 수 있습니다. |
| `/마을 청크판매 [마을명]` 또는 `/land unclaim [마을명]` | 서 있는 마을 청크를 판매할 수 있습니다. ※ 돈은 마을 잔고로 들어옵니다. |
| `/마을 삭제 [마을명]` 또는 `/land delete confirm [마을명]` | 마을 전체 청크를 판매하여 삭제합니다. |
| `/마을 스폰설정` 또는 `/land setspawn` | 마을 안에 스폰 지역을 설정합니다. |
| `/마을 스폰 [마을명]` 또는 `/land spawn [마을명]` | 설정해둔 마을 스폰으로 이동합니다. |
| `/마을 입금 [금액] [마을명]` 또는 `/land deposit [금액] [마을명]` | 마을 내 세금을 지불하거나 땅을 늘리는데 지불할 돈을 입금합니다. |
| `/마을 출금 [금액] [마을명]` 또는 `/land withdraw [금액] [마을명]` | 마을에 입금되어 있는 돈을 출금합니다. |
| `/마을 잔고확인 [마을명]` 또는 `/land balance [마을명]` | 마을 자금을 확인할 수 있습니다. |
| `/마을 탈퇴 [마을명]` 또는 `/land leave [마을명]` | 탈퇴할 마을에 서있는 상태에서 탈퇴할 수 있습니다. |
| `/land setowner 닉네임` | 마을장을 변경할 수 있습니다. |
| `/view` | 마을 청크 확인하실 수 있습니다. |

## 이사도우미

**이사 도우미 스크롤은** 마을 단위 이사를 지원하는 아이템입니다. 본인이 구매한 땅의 **청크 내 건물**을 다른 위치로 이전할 수 있습니다.

구매 후 사용 시, **디스코드 티켓을 통해 이사 문의**가 필요합니다.

### 판매처

* 후원 상점
* DP 상점
* 만물상

### 이사 티켓 가격

* 인게임 머니 : 1,000,000
* DP 포인트 : 15,000 포인트
* 캐시 : 10,000원

### 이사 전 주의사항

이사 진행 전, 커스텀 아이템은 사전에 **철거**해야 합니다.

* 커스텀 작물
* 화분통
* 비닐하우스
* 조리대
* 아이템 액자
* 플레이어 머리
* 가구류 등

### 이사 규칙

* 이사는 **본인이 구매한 땅만 가능**합니다.
* **이사 티켓 1장당 20청크** 이사가 가능합니다.
* 해당 기준은 **건축물 및 농장 모두 동일하게 적용**됩니다.
