표지판을 붙이거나 명령어를 외울 필요 없이, Shift + 우클릭만으로 설정할 수 있습니다.

> [!안내]
> * 잠금된 블록은 **본인과 등록된 친구만 사용 가능**합니다.
> * 메뉴를 이용해 **친구 추가 / 친구 삭제 / 잠금 해제** 등을 쉽게 할 수 있습니다.

> [!중요]
> **모든 상자마다 개별로 설정**해야 합니다.

## 잠그는 방법

1. 상자(또는 보호할 블록)를 바라본 상태에서 **`Shift` + `우클릭`**
2. 아래와 같은 잠금 설정 GUI가 열립니다.
3. 아래와 같이 잠금 버튼을 눌러줍니다.

### 잠근 이후 메뉴 확인

1. 다시 Shift+우클릭 시 아래와 같이 이미지가 나옵니다.

| 기능 | 설명 |
|------|------|
| **🟫 잠금 / 잠금 해제** | **블록을 보호할지 여부를 설정** |
| 🔺 사용하지 않음 | 사용하지 않는 기능 |
| **🧑 친구 관리** | **해당 블록을 함께 사용할 유저 추가/삭제** |
| 🏷️ 사용하지 않음 | 사용하지 않는 기능 |
| 📗 **복사한 구성 붙여넣기** | 복사해둔 설정 구성을 붙여넣는 기능 |
| **📄 구성 복사** | 등록해둔 설정 구성을 복사하는 기능 |

## 친구 관리

### 친구 관리 메뉴 열기

1. **`Shift` + `우클릭` → 🧑 친구 관리 아이콘 클릭**

| 기능 | 설명 |
|------|------|
| 📔 **친구 목록 보기 / 삭제** | **등록된 플레이어 목록 확인 및 제거 가능** |
| 📰 **닉네임으로 친구 추가** | **플레이어 이름 입력 후 등록** |

### 닉네임으로 친구 추가하기

1. 친구 관리 GUI에서 📰 **종이 아이콘 클릭**
2. 아래와 같은 **친구 검색 GUI**가 열립니다.
3. 상단 입력창에 **영어 닉네임**을 정확히 입력
   * 대문자 / 소문자 / 숫자 / 언더바 모두 정확하게 입력해야 합니다.
   * 예시: `Penguin___1`
4. 입력이 완료되면 **오른쪽에 있는 종이 아이템을 드래그하여 인벤토리로 꺼냅니다.**
   * 이 동작이 **확정 / 등록 완료**를 의미합니다.

### 친구 삭제 방법

1. **친구 관리 메뉴 →** 📔 **책 아이콘 클릭**
2. 목록에서 제거할 플레이어 선택 → 삭제

## 잠금 해제

1. **`Shift` + `우클릭` → 🟫 상자 아이콘 클릭**
2. 잠금 해제 시 **누구나 상자를 열 수 있으므로 주의**하세요.
