## 서버 메뉴

> [!안내] `Shift + F` 서버 메뉴를 열 수 있습니다. ( 스폰, 마을, 파밍 등)
> 
> 메뉴가 열리지 않을 경우, 설정 - 키조작 - Shift 또는 F 키가 중복된 키가 없는지 확인바랍니다.

### Shift + F → 편의성

| 메뉴/명령어 | 설명 |
|-----------|------|
| `디스코드` | 디스코드 링크를 띄워줍니다. |
| `위키` | 위키 링크를 띄어줍니다. |
| `휴지통` | 쓰레기를 버릴 수 있는 휴지통입니다. |
| `펫` 또는 `/pets` | RPG월드를 제외한 모든 서버에서 펫을 소환할 수 있습니다. |

### Shift + F → 컨텐츠

| 메뉴/명령어 | 설명 |
|-----------|------|
| `/도감` 또는 `Shift + F` - `컨텐츠 - 도감` | 도감 관리 및 도감 보상을 획득 할 수 있습니다. |
| `/dailyquests` 또는 `Shift + F` - `컨텐츠 - 퀘스트` | RPG월드를 제외한 모든 서버에서 일일퀘스트를 확인 할 수 있습니다. |
| `/스킬` 또는 `Shift + F` - `컨텐츠 - 스킬` | 생활 직업창을 열 수 있습니다. |

## 기본

| 명령어 | 설명 |
|-------|------|
| `/home` | 저장된 홈 또는 편집이 가능합니다. |
| `/home [이름]` | 저장된 홈으로 이동합니다. |
| `/sethome [이름]` | 홈을 저장하는 기능으로 이름은 영어 또는 숫자만 가능합니다. |
| `/removehome [이름]` | 저장된 홈을 지울 수 있습니다. |
| `/rt` | 1000 범위로 랜덤 이동합니다. |
| `/tpa [닉네임]` | 이동을 하고 싶은 유저에게 요청할 수 있습니다. |
| `/tpahere [닉네임]` | 상대방을 본인에게 이동을 요청할 수 있습니다. |
| `/pay [닉네임] [금액]` | 유저에게 돈을 보낼 수 있습니다. ※ 송금한 월드를 입장하여 받을 수 있습니다. |
| `/잠수 보내기 [닉네임] [금액]` | 유저에게 잠수 포인트를 보낼 수 있습니다. ※ **스폰**에서만 이용 가능합니다. |
| `/realname [한글닉네임]` | 한글 닉네임인 유저의 영어 닉네임을 확인합니다. |
| `/플라이` | 마을 내에서 플라이를 사용할 수 있습니다. |
| `/money [닉네임]` | 해당 유저 보유금액 확인 |
| `/sit` | 앉기 |
| `/spin` | 회전하기 |
| `/crawl` | 엎드리기 |

## 채팅

> [!주의] 펭귄서버에서는 전챗 및 거래챗에서는 음슴체 사용 금지입니다.

| 명령어 | 설명 |
|-------|------|
| `/전챗` | 질문을 할 수 있는 채팅채널입니다. |
| `/거래챗` | 판매 또는 구매를 하기 위한 채팅채널입니다. |
| `/지역챗` | 사담을 위한 채팅채널입니다. |
| `/귓 [한글닉]` 또는 `/tell [영어닉]` | 귓속말을 보낼 수 있습니다. |
| `/r [할말]` | 상대방이 보낸 귓속말을 대답할 수 있습니다. |

## 스폰

> [!경고] 스폰에서만 사용 가능한 명령어 입니다.

| 명령어 | 설명 |
|-------|------|
| `/추천` | 명령어를 통해 추천 사이트에 접속 후 추천을 할 수 있습니다. ※ **스폰**에서만 **보상** 지급을 해드립니다. |
| `/우편함 보내기 [닉네임]` | 손에 든 아이템을 명령어를 통해 우편을 보낼 수 있습니다. |
| `/잠수 보내기 [닉네임] [금액]` | 유저에게 잠수 포인트를 보낼 수 있습니다. |
| `/캐시 보내기 [닉네임] [금액]` | 유저에게 캐시를 보낼 수 있습니다. |
| `/계좌충전 [금액]` | 명령어를 통해 후원을 할 수 있습니다. 자세한 내용은 후원 에 있습니다. |
| `/제단 열기` | 제단 GUI를 열 수 있습니다. |
| `/제단 보상받기` | 받지않은 제단포인트 순위보상을 받습니다. |
| `/제단 개인보상` | 제물포인트 개인보상 GUI를 오픈합니다. |

## 마을

| 명령어 | 설명 |
|-------|------|
| `/마을 메뉴` 또는 `/land` | 마을 메뉴 GUI 창이 뜹니다. |
| `/마을 구매 [마을명]` 또는 `/land create [마을명]` | 서 있는 청크를 본인의 마을로 지정합니다. ※ 최대 4청크 무료, 5청크부터 2만원씩 증가 (최대 20만원) |
| `/마을 확장 [마을명]` 또는 `/land claim [마을명]` | 기존 마을 청크와 연결이 되어있는 상태에서 청크를 구매할 수 있습니다. |
| `/마을 청크판매 [마을명]` 또는 `/land unclaim [마을명]` | 서 있는 마을 청크를 판매할 수 있습니다. ※ 돈은 마을 잔고로 들어옵니다. |
| `/마을 삭제 [마을명]` 또는 `/land delete confirm [마을명]` | 마을 전체 청크를 판매하여 삭제합니다. |
| `/마을 스폰설정` 또는 `/land setspawn` | 마을 안에 스폰 지역을 설정합니다. |
| `/마을 스폰 [마을명]` 또는 `/land spawn [마을명]` | 설정해둔 마을 스폰으로 이동합니다. |
| `/마을 입금 [금액] [마을명]` 또는 `/land deposit [금액] [마을명]` | 마을 내 세금을 지불하거나 땅을 늘리는데 지불할 돈을 입금합니다. |
| `/마을 출금 [금액] [마을명]` 또는 `/land withdraw [금액] [마을명]` | 마을에 입금되어 있는 돈을 출금합니다. |
| `/마을 잔고확인 [마을명]` 또는 `/land balance [마을명]` | 마을 자금을 확인할 수 있습니다. |
| `/마을 탈퇴 [마을명]` 또는 `/land leave [마을명]` | 탈퇴할 마을에 서있는 상태에서 탈퇴할 수 있습니다. |
| `/land setowner 닉네임` | 마을장을 변경할 수 있습니다. |
| `/view` | 마을 청크 확인하실 수 있습니다. |
