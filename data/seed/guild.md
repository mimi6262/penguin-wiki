길드는 플레이어들이 함께 활동할 수 있는 서버 커뮤니티 시스템입니다. 길드에 가입하면 경험치 부스트 효과를 받을 수 있으며, 길드 레벨이 높아질수록 더 많은 길드원을 모집할 수 있습니다.

## 길드 생성

길드는 **길드 NPC**를 통해 생성할 수 있습니다.

### 생성 조건

| 조건 | 내용 |
|------|------|
| RPG 레벨 | 100 Lv 이상 |
| 생성 비용 | 20,000,000원 |

### 생성 방법

1. 길드 NPC를 클릭합니다.
2. 길드 생성 GUI에서 **[생성하기]** 버튼을 클릭합니다.

## 길드 가입 / 탈퇴

### 길드 가입

길드에 가입하려면 **가입 신청**을 해야 합니다.

```
/길드 가입신청
```

신청 이후 **길드 관리자가 승인하면 길드에 가입됩니다.**

### 길드 탈퇴

길드를 탈퇴하면 **길드 버프 효과가 사라집니다.**

* 길드 마스터는 길드를 탈퇴할 수 없으며 길드를 삭제해야 합니다.
* 길드 재가입 쿨타임 24시간입니다.

### 길드 삭제

길드 마스터만 사용할 수 있습니다.

```
/길드 제거
```

길드 삭제 시

* 모든 길드원이 자동 탈퇴됩니다.
* 길드 레벨 및 효과가 삭제됩니다.
* 생성 비용 반환되지 않습니다.

## 길드 관리 메뉴

길드를 생성한 이후 **길드 NPC를 클릭하면 길드 관리 GUI**가 열립니다.

| GUI 구성 | 위치 |
|---------|------|
| 길드원 목록 | 오른쪽 위 |
| 길드 승급 | 아래 칸 |
| 길드 설정 | 오른쪽 아래 톱니바퀴 |

### 길드 설정

톱니바퀴 아이콘을 클릭하면 **길드 설정 메뉴**가 열립니다.

| 메뉴 | 설명 |
|------|------|
| 길드명 설정 | 길드 이름 변경 |
| 길드 가입 신청현황 | 길드 가입 신청 관리 |
| 길드 계급 설정 | 길드 계급 권한 관리 |
| 멤버 관리 | 길드원 관리 |

### 길드 계급 시스템

길드는 기본적으로 **4개의 계급**으로 구성됩니다.

* 마스터
* 부마스터
* 일반 길드원
* 신입 길드원

### 계급 이름 변경

길드 계급 이름은 **자유롭게 변경할 수 있습니다.**

예시)

```
마스터 → 펭귄보스
```

### 길드 권한 설정

각 계급마다 **개별 권한을 설정할 수 있습니다.**

권한은 **ON / OFF 방식**으로 변경됩니다.

### 권한 목록

| 권한 | 설명 |
|------|------|
| 길드 가입 요청 승인 | 길드 신청 승인 |
| 길드원 퇴출 | 길드원 추방 |
| 길드명 변경 | 길드 이름 변경 |
| 경험치 부스트 적용 | 길드 경험치 버프 적용 |

## 길드 승급 및 레벨

길드는 **돈을 사용하여 레벨**을 올릴 수 있으며, 길드 마스터의 **RPG 레벨 조건**이 필요합니다.

### 승급 조건

| 길드 레벨 | 필요 비용 | 마스터 RPG 레벨 |
|---------|---------|--------|
| Lv2 | 40,000,000원 | 120 Lv |
| Lv3 | 60,000,000원 | 140 Lv |
| Lv4 | 100,000,000원 | 160 Lv |

### 길드 효과

길드 레벨에 따라 **개인 RPG 경험치 부스트 효과** 및 **패시브 스킬 효과**가 적용됩니다. 패시브 스킬 수치는 자신의 **최대 능력치 기준 퍼센트**로 적용되며, 별도 UI에 표기되지 않습니다.

| 길드 레벨 | RPG 경험치 | 데미지 | 최대 체력 | 최대 마나 |
|---------|----------|-------|---------|--------|
| Lv1 | +5% | +1% | +1% | +1% |
| Lv2 | +10% | +3% | +3% | +3% |
| Lv3 | +15% | +5% | +5% | +5% |
| Lv4 | +20% | +8% | +8% | +8% |

### 길드 경험치 버프 적용 방식

* 효과는 길드원 개인에게 적용됩니다.
* 길드에 가입한 동안 상시 적용됩니다.
* 길드를 탈퇴하면 버프 효과는 즉시 사라집니다.
* 길드 레벨에 따라 버프 수치가 달라집니다.

### 길드 인원 제한

길드 레벨에 따라 **가입 가능한 길드원 수가 증가합니다.**

| 길드 레벨 | 최대 인원 |
|---------|--------|
| Lv1 | 3명 |
| Lv2 | 6명 |
| Lv3 | 9명 |
| Lv4 | 12명 |

## 길드 명령어

현재 사용 가능한 길드 명령어입니다.

| 명령어 | 설명 |
|-------|------|
| `/길드 생성` | 길드 생성 |
| `/길드 가입신청` | 길드 가입 신청 |
| `/길드 제거` | 길드 삭제 |
| `/길드채팅` | 길드 전용 채팅 |
