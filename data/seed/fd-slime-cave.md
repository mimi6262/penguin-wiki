## 슬라임 굴

| 드랍 아이템 | 설명 |
|---|---|
| 그린 슬라임 볼 | 슬라임에게 드랍되며 4티어 장비(무기,모자,룬)의 재료로 사용됩니다. |
| 블루 슬라임 볼 | 푸른 슬라임에게 드랍되며 4티어 장비(무기,갑옷,룬)의 재료로 사용됩니다. |
| 블랙 슬라임 볼 | 슬라임 워리어에게 드랍되며 4티어 장비(무기,바지,룬)의 재료로 사용됩니다. |
| 퍼플 슬라임 볼 | 트리플 슬라임에게 드랍되며 4티어 장비(무기,신발,룬)의 재료로 사용됩니다. |
| 3티어 정수 | 슬라임굴의 모든 몹에게 드랍되며 모든 아이템의 재료로 사용됩니다. |
| 3티어 제련석 조각 | 슬라임굴의 모든 몹에게 드랍되며 4개로 제련석으로 조합이 가능합니다. |
| 3티어 제련석 | 제련석 조각으로 만들수 있으며 모든 아이템의 재료로 사용됩니다. |
