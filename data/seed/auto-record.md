영상 증거가 있으면 문제 상황을 더 빠르게 확인하고 처리할 수 있습니다. Windows 11 기준으로 작성되었으며, Windows 10도 동일한 방식으로 설정 가능합니다.

## 녹화 프로그램 종류

> [!안내] 3가지 중 **원하는 방법으로 선택**해서 사용해주세요.

1. Replay Mod(리플레이 모드) - **권장**
2. OBS Studio
3. Windows 내부 설정

---

### 1. Replay Mod (리플레이 모드)

> [!안내] 나중에 시점 돌려보면서 어디서 잃어버렸는지 정확히 확인하기 좋음

1. 해당 프로그램을 다운받습니다.
2. AppData\Roaming\.minecraft\\**mods** 경로로 들어가 다운받은 파일을 넣습니다.
3. 게임을 재시작 합니다.
4. 게임 내 > 설정 - 조작 - 키지정에 간 후, replaymod 항목에서 중복된 키는 esc를 통해 제거하여 사용합니다.

---

### 2. OBS Studio 사용 시

> [!안내] 플레이 당시 화면이 그대로 남아서 분실 직전 상황을 다시 보기에 좋음

다운로드 링크: https://obsproject.com/ko

1. 링크에 들어가 파일을 다운로드 한 뒤, 설치합니다.
2. OBS를 실행한 뒤, 아래의 이미지에 적힌 숫자 순서대로 누릅니다.
3. 이후, 녹화중단을 원하시면 [녹화 중단]을 누릅니다. 녹화 중단 시, 자동저장됩니다.
4. 저장 경로 : C:\Users\\**PC이름**\Videos (동영상 폴더)

---

### 3. Windows 설정으로 사용 시

> [!안내] 급할 때 바로 켜서 간단하게 이동 경로나 행동 기록하기 좋음

1. 윈도우 검색창에 '**캡처 설정**'을 입력해서 실행합니다.
2. 발생 상황 녹화 **[켬]**으로 설정합니다.
3. **마지막 플레이 녹화시간**을 원하는 값으로 변경합니다.
4. 캡처 설정 창을 닫은 뒤, 플레이 도중 버그 발생 시, **윈도우+Alt+G**를 누르면 마지막 플레이 녹화시간이 저장됩니다.
5. 저장된 경로는 C:\Users\\**PC이름**\Videos\Captures

> [!주의] 버그 제보나 아이템 분실 신고 시, "녹화 영상이 함께 제공되면 훨씬 빠르게 확인 및 처리"할 수 있습니다. 가능하다면 위 가이드를 따라 녹화를 진행하고, 티켓에 영상 파일 또는 링크를 첨부해 주세요.
